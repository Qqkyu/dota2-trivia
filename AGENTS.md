## Agent skills

### Issue tracker

Issues live in GitHub Issues on `Qqkyu/dota2-trivia` via `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Feedback sounds

Lock click, pick silence, wrong-answer cave/echo, or `pnpm check:sounds`: follow
`docs/adr/0001-feedback-sounds.md`. Known-good tag: `checkpoint-sounds-ok`.
