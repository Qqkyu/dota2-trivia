# Hosted browser diagnostic

The [original hosted run](original-hosted-failure.json) passed all 13 public formats and the private guest vote/reveal flow, then failed with `BROWSER_RUNTIME`. It forwarded 639 browser requests and confirmed private room cleanup. It did not retain the browser failure counters, so the exact cause remains unknown.

The later [browser-only run](browser-diagnostic-1791701345130.json) passed on 11 October 2026. It used the same deployed commit `31961cbd762587225b4b8a814828dc0829952978`, from successful CI run `38050315807`. Its final health and deployment checks passed. The fresh browser context reached answering and reveal, with prompt, timer, and answer controls present at 320 by 568 and 1440 by 1000 pixels. Neither view had horizontal overflow. This checks two browser viewport sizes, not physical devices or every layout and format.

The browser stage took 37.342 seconds. It observed 360 routed requests and forwarded 359, including 304 public game CDN requests and 11 round API requests. It blocked one session write and sent no votes or private room writes. It stayed within the 640-request and 90-second browser limits. The run recorded zero page errors and no proxy failure. It also recorded one coded console network error and two failed request events. These records remain in the exact result; a passing run does not mean all requests succeeded.

The [wrapper source](browser-only.mjs.txt) has SHA-256 `695558a482a668f872e602351d527f09b10a3ecb24eed7b8e25a636880536627`. It imports the unchanged [reviewed helper](../private-reveal-wait-v3/hosted-smoke.mjs.txt), checks its hash, and retains its gate, deployment, origin, credential, write, request, byte, time, and cleanup guards. Independent read-only review found no blocker in this pinned wrapper. The source snapshots depend on the private gate and imported helper; they are not a standalone replay package. The existing [helper review](../private-reveal-wait-v3/review.json) remains separate. It records coded errors and hashes of the origin plus path, with no query strings. Its path map stops at 256 entries, reports 30 overflow observations, and retains only the top 32 hashes. Diagnostic metrics are captured before browser teardown, so requests still in flight can make final totals differ.

The browser uses a bounded Node proxy with Playwright routing. This changes the request and cache path from a normal browser. The [local comparison](local-cache-comparison.json) used the actual reviewed proxy with a synthetic page and repeated image mounts on loopback. It made no hosted requests. Both the default routing setup and an explicit Chromium cache-enable command produced 659 routed requests, 638 forwarded local requests, and a request-budget stop. All five image stages loaded; only 5 of the following 24 extra assets loaded. The cache command did not reduce these routed requests.

The [comparison source](local-cache-comparison.mjs.txt) checks that the proxy blocks a synthetic write and a foreign origin, strips request credentials, and does not store a response cookie. Both variants recorded zero credential or foreign forwarding, zero private writes, and stopped browsers. The operator reported exit code 0 and closure of the local server. This fixture shows a way that repeated proxy requests can exhaust the existing budget. It does not replay the original hosted sequence, establish its failure cause, or measure normal browser cache behavior. No app or proxy fix is claimed.

The first local comparison attempt did not execute because automatic permission review timed out. One authorized retry completed. This [review record](review.json) identifies that statement as the coordinating operator's record after completion, not an execution attestation.

The reports do not record the browser version or an observed runtime build ID. Their deployment checks bind the provider deployment and candidate commit. No account-holder Steam login is proved here. The browser diagnostic sent no votes. The original run's one private guest vote and room cleanup remain separate evidence. The archive contains no raw credentials, room identifiers, URL queries, request bodies, or browser profiles. The local fixture source uses clearly marked synthetic credentials.
