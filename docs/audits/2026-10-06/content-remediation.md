# Content audit fixes

Review date: 2026-10-06. This records changes after the [original content audit](content.md). Existing user edits were preserved. No full upstream data sync was run.

Expected result: each confirmed answer defect has a clear player-visible answer space, stored data passes the live catalog gates, and release checks detect missing source evidence or content that changed after review. Checks cover the public question output, current stored catalogs, published patch deltas, and media availability.

## Changes

- **C-01:** `soundcheck-item:force_staff` uses its four reviewed options. Hurricane Pike is excluded because it shares the cue. Other single-item sounds retain the full shop. The shared-cue list now supplies both the runtime choice rule and the validator. The validator checks the actual answer space. A separate presentation revision prevents the earlier ambiguous full-shop results from affecting the corrected question's calibration; Blink Dagger's revision is unchanged.
- **C-02:** Order Up damage cards use the structured damage measurements in `scripts/damage-question-facts.mjs`. Card text and reveal labels preserve base damage, one healing pulse, one meteor, and conditional bonuses. Rolling Boulder excludes the Strength bonus; Scatterblast uses targets outside point-blank range. Finger of Death excludes kill stacks and Culling Blade assumes a target above the execution threshold. A shared detail states the exclusions for talents, upgrades, amplification, and resistance. All 80 Order Up rows were regenerated locally from committed source questions. The 12 damage rounds keep their numeric answers and order.
- **C-03/C-05:** Nine Flashback rows were changed. The courier question now scores Animal Courier for 7.23, in its existing correct slot B. Corrections cover Techies' release date, the last Shrines, the first Battle Pass, The Play's match stage, and Refresher Shard's current effect. Four broad homepage citations were replaced with specific sources. The question IDs and evidence are listed below.
- **C-04:** The Shopkeeper quality gate accepts the intended `/arcade/items/<key>.png` paths. Both existing local-art questions now enter the live catalog. The local-file validator still checks the files. Shopkeeper has 102 playable rows; the full live catalog has 1,517.
- **C-06:** Asset validation loads all six question catalogs and both hero/item pickers. It includes Flashback order cards and reveal media. It checks local file headers and remote successful responses, MIME types, and media headers. An HTML error page with HTTP 200 fails the check. The command also covers archived rows, so its scope is larger than the current live deck.
- **C-07:** Missing local client sources now produce an explicit `SKIPPED` message. `--require-client` makes these checks fail when a source is absent. `audit-live-client.mjs` checks SHA-256 hashes and the full hero-file list for 131 pre-existing extracted build 6882 inputs before using them. It applies 13 separately recorded numeric changes from [Valve's English 7.41f patch feed](https://www.dota2.com/datafeed/patchnotes?version=7.41f&language=english), with expected before/after values. The delta helper does not import generator overrides. Unexpected base values fail. This corrects the six false failures against the older base. Power Cogs' future generator override was also corrected to the published flat 90 mana cost; no current stored question depended on the previous level array.
- **C-08:** The new release review manifest binds every JSON file under `src/data` and every `.mjs` file under `scripts`, the gameplay patch, the source audit metadata, and this review evidence. Validation fails for changed, new, or missing files, missing evidence, and a missing manifest. Validation does not create a review record. The main check command and CI require this gate. Record the final manifest only after the other script changes are complete.
- **C-09 and notices:** The five composite Flashback order questions now have 22 primary references covering all 20 event cards, stored under `source.references` with each card's key. Their main URLs also point to event pages. No Dota homepage citations remain. The validator requires per-card source coverage for these rows. [Composite source evidence](flashback-sources.md) records the pages and date checks. Exact OpenDota and Dotabase MIT notices are preserved in [THIRD_PARTY_NOTICES.md](../../../THIRD_PARTY_NOTICES.md). [Content source documentation](../../content-sources.md) records missing original download provenance and unknown creator/source/reuse permission for the 23 local venue and winner assets. No photo permission is asserted and no photo was removed.

The content version was advanced for Shopkeeper, Soundcheck, Order Up, and Flashback. A stale schema-text assertion in the Shopkeeper validator was removed after schema creation moved to explicit migrations; database migration tests cover that schema behavior.

## Remaining limits

The known incorrect examples and all nine homepage citations have been addressed. Other legacy wiki citations and raw source labels remain in the wider historical catalog; their presence is not evidence that the facts are wrong. The present public output does not display sources. The source validator checks structure and event coverage, while the linked review records the independent factual checks.

Media-header checks do not fully decode every asset or establish that the picture or sound is the intended subject. Every clip was not listened to again. Public question serialization was exercised directly; the parent workstream owns browser gameplay verification.

The 131 file hashes pin the pre-existing extracted client bytes; they do not independently prove the original acquisition or the claimed build. The patch overlay covers numeric fields used by the client comparison. It does not prove every localization sentence, upgrade effect, or mechanic against a newly downloaded current client. The patch-feed hash records the English response reviewed on this date; the response body remains in the local review evidence rather than being redistributed in the repository.

Original OpenDota/Dotabase input snapshots remain unavailable. The release manifest detects later byte changes; it cannot recover those downloads or guarantee that upstream facts will stay current. Photo and other game-asset permissions require separate release review. Source notices do not establish those permissions.
